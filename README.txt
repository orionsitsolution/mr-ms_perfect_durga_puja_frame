DURGA PUJA GIFT FRAME MAKER - deploy notes
==========================================

1. Upload index.html to your web server (public_html / www / any static host).
   It is ONE self-contained file - no other files, no database, no PHP needed.
2. Open it at https://yourdomain.com/  (or /frame/ if you put it in a folder).

IMPORTANT
- Use HTTPS. Browsers only allow the laptop webcam ("Take photo" on desktop)
  on https:// pages (or localhost). Upload + download work on plain http too.
- Phones: "Take photo" opens the phone's own camera app - works on http and https.
- Download saves durga-puja-gift-frame.jpg (1080 x 1394 px) with a small
  "Powered by Orions InfoTech Solution" strip at the bottom.
- The footer link goes to https://orionsitsolution.com/
- Fonts load from Google Fonts; if offline, safe system fonts are used.
